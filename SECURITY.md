# Security Policy

## Supported Versions
Only the latest commit on the `main` branch deployed to GitHub Pages is supported.

| Version | Supported |
| :--- | :--- |
| main (latest) | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability
To report a security vulnerability or credential leak:
1. Do not open a public GitHub issue.
2. Open a private security advisory via GitHub under the **Security** tab -> **Report a vulnerability**.
3. Telemetry ingestion vulnerabilities or invalid sanitization vectors will be evaluated within 48 hours.
